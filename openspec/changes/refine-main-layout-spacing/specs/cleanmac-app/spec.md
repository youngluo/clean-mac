## MODIFIED Requirements

### Requirement: 清理任务选择

空闲界面 SHALL 提供一个主清理操作，并在主界面状态切换时保持圆形主操作的垂直位置一致。该操作 SHALL 启动统一扫描，覆盖安全清理、已卸载应用残留、项目产物和合并后的大文件扫描。空闲界面不得再提供独立的大文件扫描或开发清理主入口。

#### Scenario: 启动统一清理

- **WHEN** 用户点击“一键清理”
- **THEN** 应用启动统一的只读扫描
- **AND** 不要求用户先选择独立的清理类别

#### Scenario: 启动磁盘访问受限

- **WHEN** macOS 尚未授予 CleanMac 完全磁盘访问权限
- **THEN** 统一扫描继续检查可读取的位置
- **AND** 同一主界面显示一条合并的权限提示，并提供前往系统设置的操作
- **AND** 权限提示使用“需要完全磁盘访问”和“开启后，扫描结果会更完整”的简短单行文案
- **AND** “去设置”和重新检查操作保持统一高度和紧凑间距，不挤压提示文案
- **AND** “去设置”以纯文字操作展示，不额外显示图标
- **AND** 所有可用的界面操作在悬停时显示手形指针，禁用操作保持默认指针

#### Scenario: 空闲主操作布局

- **WHEN** 应用处于空闲状态
- **THEN** 顶部磁盘信息与圆形主操作之间有明确的垂直留白
- **AND** 圆形主操作与说明文字、权限提示之间保持舒适的垂直间距
- **AND** 圆球尺寸、主操作文案和清理行为保持不变

#### Scenario: 圆形主操作位置一致

- **WHEN** 应用在空闲、扫描、等待确认、清理中、完成或部分完成状态之间切换
- **THEN** 圆形主操作与顶部磁盘信息之间使用一致的垂直定位
- **AND** 工作状态动画不改变圆球中心位置
- **AND** 空闲和工作状态使用一致的圆球基础样式
- **AND** 悬停状态通过可感知但柔和的缩放和光晕反馈，正在扫描状态通过明显但克制的缩放和阴影呼吸反馈
- **AND** 上述视觉反馈不绘制突兀的轮廓线，也不改变圆球中心位置
- **AND** 工作状态的圆形主操作与 provider 状态面板之间保留稳定的视觉缓冲，阴影和缩放不侵入面板内容
- **AND** 圆球呼吸效果仅在正在扫描状态显示，清理执行、完成、部分完成和空闲状态不显示呼吸效果
- **AND** 弹出窗口在内容高度变化时使用窗口自身的尺寸过渡，不对内容树附加全局布局动画
- **AND** 扫描和清理进行中不显示尚未开始的 provider 占位内容，并关闭高频内容更新触发的窗口尺寸动画
- **AND** 进入扫描结果或完成状态时恢复窗口尺寸动画
- **AND** 圆球尺寸、文案和清理行为保持不变

#### Scenario: 复核候选项

- **WHEN** 统一扫描发现需要确认的候选项
- **THEN** 同一主界面按类型分组展示候选项
- **AND** 不自动选中应用残留、项目依赖或大文件扫描候选项

#### Scenario: Provider 空结果状态

- **WHEN** provider 扫描结果为 0 项
- **THEN** provider 状态行使用正常完成图标，不使用感叹号图标
- **AND** provider 的状态行仍保留 0 项文案
- **AND** partial 且存在候选项时继续使用警示图标

#### Scenario: 过滤空清理候选

- **WHEN** 可清理文件或目录的实际大小明确为 0 KB
- **THEN** 应用不将其展示为可清理候选项
- **AND** 大小未知的内容仍可作为候选项展示

#### Scenario: 展示已选与总大小

- **WHEN** 候选列表展示“可清理项目”标题
- **THEN** 标题右侧显示当前已选候选项的大小和全部候选项的已知大小总和
- **AND** 两个大小值使用 `/` 分隔

#### Scenario: 点击候选项名称选择

- **WHEN** 用户点击可选候选项的名称
- **THEN** 应用切换该候选项的选中状态
- **AND** 点击选择图标与点击名称使用相同的切换逻辑
- **AND** 点击路径、大小或行内空白不触发选择
- **AND** 已完成、受保护或其他不可选候选项不响应选择操作

#### Scenario: 清理执行期间保持操作按钮

- **WHEN** 用户点击“移到废纸篓”并进入清理执行状态
- **THEN** “移到废纸篓”按钮继续显示但处于禁用状态
- **AND** 圆球显示“正在清理”
- **AND** “完成”按钮继续显示但处于禁用状态，不可中断当前流程
- **AND** 操作区从左到右依次排列“移到废纸篓”、重新扫描和完成/取消，重新扫描隐藏时不改变主操作的最左位置
- **WHEN** 清理完成或部分完成
- **THEN** 圆球显示“清理完成”
- **AND** 完成操作恢复可用
- **AND** 候选项目列表继续保留在当前界面，不因状态切换重置
- **AND** 候选项目列表保持清理前的滚动位置

## ADDED Requirements

### Requirement: 主题色与应用图标保持一致

应用 SHALL 以 App 图标中的鼠尾草绿和暖象牙白作为品牌色锚点，同时为警告和失败状态提供独立、可区分的语义色。面板背景、边框和正文 SHALL 继续使用系统材质与系统文本颜色，避免品牌色覆盖整个界面。

#### Scenario: 主操作使用品牌色

- **WHEN** 用户查看主操作、一般强调或扫描中的进度状态
- **THEN** 相关颜色使用同一鼠尾草绿色系
- **AND** 主操作前景使用暖象牙白，保证与按钮背景形成清晰对比

#### Scenario: 主操作按钮保持统一

- **WHEN** 用户查看圆形主操作或“移到废纸篓”按钮
- **THEN** 两者使用同一深鼠尾草绿主操作背景
- **AND** 两者使用同一暖象牙白前景
- **AND** 重新扫描、完成和取消按钮继续使用中性次要样式

#### Scenario: 状态颜色保持语义区分

- **WHEN** 界面展示成功、警告或失败状态
- **THEN** 成功使用较深的绿色，警告使用琥珀色，失败使用低饱和砖红色
- **AND** 警告与失败不复用品牌强调色

#### Scenario: 菜单栏图标保持系统模板行为

- **WHEN** macOS 在菜单栏显示 CleanMac 图标
- **THEN** 图标继续使用 template rendering 的单色行为
- **AND** 主题色调整不改变菜单栏图标的系统适配方式

#### Scenario: 清理成功结果保持简洁

- **WHEN** 候选项清理成功并进入 `movedToTrash` 或 `removed` 状态
- **THEN** 候选行保留成功图标
- **AND** 不在路径下方重复显示“已移到废纸篓”或“已清理”等成功结果文案
- **WHEN** 候选项失败、跳过或取消
- **THEN** 候选行继续显示对应的结果文案，失败时优先显示具体失败消息

#### Scenario: 主题色与毛玻璃层次保持协调

- **WHEN** 用户查看主操作、成功、警告或失败状态
- **THEN** 主操作使用 `#589665`，成功使用 `#579364`，警告使用 `#D99B4D`，失败继续使用低饱和砖红色
- **WHEN** 用户查看主弹出层或内容面板
- **THEN** 界面继续使用系统毛玻璃材质
- **AND** 材质比原来的超薄效果更凝实，并减少背景透出
- **AND** 不使用纯色背景覆盖系统材质
- **AND** 毛玻璃下方使用动态中性系统底色，不使用鼠尾草绿 tint 给面板整体着色
- **AND** NSPopover 的箭头、外壳和 SwiftUI 根视图由同一套原生 Popover 背景材质承接
- **AND** NSPopover、HostingView 和内容窗口使用同一个动态系统外观
- **AND** SwiftUI 根视图不使用不透明背景覆盖 Popover 原生材质
- **AND** 毛玻璃效果保留在内部内容面板，不在根视图额外叠加与原生外壳冲突的材质层

#### Scenario: 语义状态使用系统色

- **WHEN** 用户查看选中、成功、警告或失败状态
- **THEN** 选中使用 macOS `systemBlue`
- **AND** 成功使用 macOS `systemGreen`
- **AND** 警告使用 macOS `systemOrange`
- **AND** 失败使用 macOS `systemRed`
- **AND** 正在扫描使用 macOS `systemBlue`
- **AND** 主操作和品牌强调仍可使用 App 图标对应的鼠尾草绿

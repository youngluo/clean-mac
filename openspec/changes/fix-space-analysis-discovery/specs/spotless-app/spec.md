## MODIFIED Requirements

### Requirement: 清理任务行为

应用 SHALL 保持扫描只读，绝不将清理作为扫描的副作用。扫描完成后，应用 SHALL 要求用户明确确认清理方案，才可以执行任何文件或目录操作。统一流程 SHALL 包含深度清理、应用和残留发现、缓存与服务刷新、项目产物，以及合并后的空间分析（安装包、压缩包、指定目录中的大文件和 Time Machine 检查）。缓存清理 SHALL 额外覆盖已配置的开发工具缓存以及多个受安全规则约束的临时目录。除 `~/Downloads`、`~/Desktop`、`~/Documents` 中普通文件大于 10 MB 的专门规则外，空间分析不设置通用固定体积阈值。

#### Scenario: 只读扫描

- **WHEN** 统一扫描完成并发现范围受限的安全缓存、日志或刷新候选项
- **THEN** 应用展示候选项但不改变文件系统
- **AND** 在确认前不执行任何候选项

#### Scenario: 启动磁盘分析

- **WHEN** 统一扫描分析本地启动磁盘
- **THEN** 报告总容量、可用空间和可测量的已占用空间
- **AND** 将外置、可移除、网络和受保护磁盘排除在启动磁盘大文件候选项之外
- **AND** 只保护系统 Photos.app、Music.app 及其明确关联的数据，不整目录排除用户的 `Pictures`、`Music` 和 `Movies`
- **AND** `Downloads`、`Desktop` 和 `Documents` 中逻辑大小大于 10 MB 的普通文件进入候选评估
- **AND** 安装包和压缩包等特殊文件保持现有候选规则
- **AND** 先完成路径、卷和保护边界判断再读取条目元数据，已读取的文件属性在同一次遍历中复用
- **AND** 标准目录优先处理，不能因全盘其它目录超时而跳过已经可访问的标准目录
- **AND** 元数据读取失败时报告部分扫描诊断，不静默丢弃整个分析结果
- **AND** 同一个文件通过硬链接出现多次时只计入一次空间统计和候选集合
- **AND** 在统一扫描中，空间分析只跳过缓存清理、项目清理和应用残留实际生成的候选路径及其子项，避免重复展示
- **AND** 前述 provider 因近期修改、归属不明确或读取失败没有生成候选时，空间分析仍可评估其中符合规则的文件
- **AND** 被前三类候选覆盖的路径仍计入空间统计，不因候选屏蔽而减少空间概览的可测量占用
- **AND** 不限制空间分析候选项数量，不新增空间概览或候选数量相关界面

#### Scenario: 空间分析部分完成但已有候选时显示可用状态

- **WHEN** 空间分析因受保护或不可读取路径被标记为部分完成
- **AND** 已经发现一个或多个可复核候选项
- **THEN** provider 状态行显示成功勾选和成功色
- **AND** 继续显示已有候选数量和实际大小
- **AND** 不改变其它 provider 的部分完成状态显示规则

#### Scenario: 系统应用关联媒体数据保持受保护

- **WHEN** 启动磁盘分析遇到系统 Photos.app、Music.app 或其稳定应用容器、图库和资料库数据
- **THEN** 应用将这些路径计入受保护空间但不创建可选择候选
- **AND** 不因路径位于用户 `Pictures`、`Music` 或 `Movies` 目录就保护同目录下与系统应用无关的普通文件

#### Scenario: Time Machine 检查

- **WHEN** 统一扫描检查 Time Machine
- **THEN** 将快照状态和可用性作为分析信息报告
- **AND** 在执行任何快照维护操作前要求用户明确确认

#### Scenario: 没有可维护的本地快照

- **WHEN** `tmutil listlocalsnapshots /` 只返回任意格式的磁盘标题、系统管理快照或没有实际可维护的 Time Machine 快照记录
- **THEN** 空间分析不创建 Time Machine 快照候选项
- **AND** 保留“未发现本地快照”的扫描诊断
- **AND** 空间分析项目计数不因标题行或系统管理快照增加

#### Scenario: 存在可维护的本地快照

- **WHEN** `tmutil listlocalsnapshots /` 返回一个或多个 `com.apple.TimeMachine.*` 实际快照记录
- **THEN** 空间分析创建一个聚合的 Time Machine 维护候选项
- **AND** 该候选项保持待确认状态

#### Scenario: 项目产物

- **WHEN** 统一扫描发现已识别的项目产物
- **THEN** 报告其路径、类别以及可测量的体积
- **AND** 保护近期、不明确的项目，不允许选中

#### Scenario: 扫描后候选项内容变化

- **WHEN** 用户确认清理后，候选文件或目录的身份或可测量体积与扫描时不同
- **THEN** 应用不移动或删除该候选项
- **AND** 将其报告为“扫描后内容已变化，请重新扫描后再清理”
- **AND** 部分清理结果仍然保留，不重复执行已经完成的候选项
- **AND** 用户点击“完成”返回空闲页后，可以从主清理入口重新开始统一扫描

#### Scenario: 路径策略校验失败

- **WHEN** 候选路径不在允许根目录、命中排除或保护规则、是符号链接或已不存在
- **THEN** 应用不移动或删除该候选项
- **AND** 使用对应的路径或安全校验原因报告失败

#### Scenario: 动态缓存目录

- **WHEN** DerivedData 等允许清理的缓存目录在扫描后继续被进程修改
- **THEN** 应用将其视为内容变化而不是非法路径
- **AND** 应用要求用户重新确认当前目录内容后再执行清理

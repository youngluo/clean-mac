## MODIFIED Requirements

### Requirement: 单界面清理交互

应用 SHALL 在同一个主弹出面板中呈现空闲、扫描中、等待确认、清理中和结果状态。状态变化 SHALL 更新当前界面内容，不应跳转到独立的清理、分析或完成页面。

#### Scenario: 统一进度界面

- **WHEN** 用户启动统一扫描或清理
- **THEN** 同一界面显示当前阶段、进度和取消控制
- **AND** 只使用一个主要阶段提示，不额外叠加 loading
- **AND** 圆形主按钮与 provider 进度面板之间不显示额外的阶段辅助行，扫描和清理状态由圆形按钮及 provider 区域表达

#### Scenario: 圆形主操作反馈

- **WHEN** 用户将鼠标移到“一键清理”圆形按钮上或按下按钮
- **THEN** 按钮使用 macOS 系统蓝，仅显示白色阶段文案、短暂的白色边缘和轻微的抬升、回弹反馈
- **AND** 用户启动扫描后，圆形按钮通过整体轻微呼吸、抬升和倾斜表达当前工作状态，不额外显示 loading
- **AND** 扫描阶段日志中处于“扫描中”的 provider 使用循环箭头图标并持续旋转，进入清理阶段后停止旋转
- **AND** 开启减少动态效果时不显示悬停环和微动

#### Scenario: 检查完成仍留在主界面

- **WHEN** 统一扫描完成并进入等待确认
- **THEN** 同一主界面的圆形按钮显示“扫描完成”文案，不显示图标
- **AND** 圆形按钮停止呼吸、抬升和倾斜动效
- **AND** provider 日志位于圆形按钮下方，候选结果和确认操作位于日志下方
- **AND** 圆形主按钮与 provider 日志之间不显示额外的阶段辅助行
- **AND** provider 分类列表在扫描完成后显示“已扫描完成”标题
- **AND** provider 和可清理项目分组统一使用“缓存清理”“项目清理”“应用残留”“空间分析”名称
- **AND** 仅扫描中的 provider 在名称下显示一行仅含对应扫描范围的说明文案，扫描完成后通过短动画收拢隐藏说明占用的间距，减少动态效果设置下直接收拢
- **AND** 有对应候选分组的 provider 行可点击，并将候选列表滚动到同名分组标题；没有对应候选分组的 provider 行不可点击
- **AND** 扫描完成后的 provider 行和候选分组使用紧凑的垂直间距，状态切换不发生瞬间跳变
- **AND** provider 日志在有可测量数据时显示对应候选体积
- **AND** 大文件扫描有候选但没有可测量体积时显示“大小未知”

#### Scenario: 等待确认

- **WHEN** 只读扫描完成
- **THEN** 同一界面保留所有可处理候选项
- **AND** 选择变化不会把候选项从列表中移除
- **AND** 每个候选项展示单行路径，过长路径使用末尾省略，悬停可查看完整路径
- **AND** 候选区标题展示“可清理项目”、已选数量和已选项目的总大小
- **AND** 每个候选项上侧展示名称和可测量体积，下侧展示单行路径，分类汇总由分组标题承担
- **AND** 分组标题与候选区顶部内容保持一致的水平边距
- **AND** 具体项目列表的可滚动区域最小高度为 320，最大高度为 640，超出最大高度后滚动
- **AND** 候选分组之间使用紧凑留白，不绘制可见横向分隔线，provider 跳转使用稳定的分组标识定位到对应分组
- **AND** 每个 provider 锚点包含一致的顶部留白，首个“缓存清理”分组滚动后不贴近候选标题栏
- **AND** 分组默认展示和锚点滚动后的顶部留白保持一致
- **AND** 候选标题栏与具体项目列表保持清晰分隔，路径默认使用中性文字，交互时使用主题强调色
- **AND** 路径仅用于识别候选位置，不提供打开路径操作
- **AND** “移到废纸篓”和“取消”按钮在候选列表下方按内容宽度紧凑居中并列展示
- **AND** 候选项使用紧凑的圆形复选框
- **AND** 不移动或删除任何文件和目录

#### Scenario: 直接移到废纸篓

- **WHEN** 用户点击“移到废纸篓”
- **THEN** 应用开始执行清理操作
- **AND** 选中的文件和目录通过 macOS 废纸篓处理

#### Scenario: 执行前取消

- **WHEN** 用户在执行前点击“取消”
- **THEN** 应用返回候选项列表
- **AND** 不改变任何文件或目录

#### Scenario: 清理完成仍留在主界面

- **WHEN** 扫描或确认后的清理完成
- **THEN** 同一界面显示圆形按钮文案“清理完成”以及“可清理项目”列表
- **AND** 已处理候选项直接在原列表行显示“已移到废纸篓”“已清理”“失败”等状态
- **AND** 不显示独立的清理前后空间汇总、统计卡片或清理结果明细列表
- **AND** 仍未处理的候选项继续留在列表中，用户可以不离开该界面继续选择和确认

#### Scenario: 语言一致性

- **WHEN** 用户在右键菜单中选择应用语言
- **THEN** 主界面和右键菜单使用同一语言显示
- **AND** 扫描、清理或结果处理进行中不允许切换语言
- **AND** 语言切换不会改变当前清理候选项或文件系统状态
- **AND** 应用生成的扫描、诊断和清理结果消息在展示时按当前应用语言解析
- **AND** 未分类的系统或外部命令原文不被本地化层改写

## MODIFIED Requirements

### Requirement: 清理任务选择

空闲界面 SHALL 提供一个主清理操作，并在主界面状态切换时保持圆形主操作的垂直位置一致。该操作 SHALL 启动统一扫描，覆盖安全清理、已卸载应用残留、项目产物和合并后的大文件扫描。空闲界面不得再提供独立的大文件扫描或开发清理主入口。

#### Scenario: 启动统一清理

- **WHEN** 用户点击“一键清理”
- **THEN** 应用启动统一的只读扫描
- **AND** 不要求用户先选择独立的清理类别

#### Scenario: 启动磁盘访问受限

- **WHEN** macOS 尚未授予 CleanMac 完全磁盘访问权限
- **THEN** 统一扫描继续检查可读取的位置
- **AND** 同一主界面显示一条合并的权限提示，并提供前往系统设置的操作
- **AND** 权限提示使用“需要完全磁盘访问”和“开启后，扫描结果会更完整”的简短单行文案
- **AND** “去设置”操作保持统一高度和紧凑间距，不挤压提示文案
- **AND** “去设置”以纯文字操作展示，不额外显示图标
- **AND** 所有可用的界面操作在悬停时显示手形指针，禁用操作保持默认指针

#### Scenario: 空闲主操作布局

- **WHEN** 应用处于空闲状态
- **THEN** 顶部磁盘信息与圆形主操作之间有明确的垂直留白
- **AND** 圆形主操作与说明文字、权限提示之间保持舒适的垂直间距
- **AND** 圆球尺寸、主操作文案和清理行为保持不变

#### Scenario: 圆形主操作位置一致

- **WHEN** 应用在空闲、扫描、等待确认、清理中、完成或部分完成状态之间切换
- **THEN** 圆形主操作与顶部磁盘信息之间使用一致的垂直定位
- **AND** 工作状态动画不改变圆球中心位置
- **AND** 空闲和工作状态使用一致的圆球基础样式
- **AND** 悬停状态通过可感知但柔和的缩放和光晕反馈，正在扫描状态通过明显但克制的缩放和阴影呼吸反馈
- **AND** 上述视觉反馈不绘制突兀的轮廓线，也不改变圆球中心位置
- **AND** 工作状态的圆形主操作与 provider 状态面板之间保留稳定的视觉缓冲，阴影和缩放不侵入面板内容
- **AND** 圆球呼吸效果仅在正在扫描状态显示，清理执行、完成、部分完成和空闲状态不显示呼吸效果
- **AND** 弹出窗口在内容高度变化时使用窗口自身的尺寸过渡，不对内容树附加全局布局动画
- **AND** 扫描和清理进行中不显示尚未开始的 provider 占位内容，并关闭高频内容更新触发的窗口尺寸动画
- **AND** 进入扫描结果或完成状态时恢复窗口尺寸动画
- **AND** 圆球尺寸、文案和清理行为保持不变

#### Scenario: 主界面隐藏重复品牌标识

- **WHEN** 用户打开 CleanMac 主界面
- **THEN** 顶部显示启动磁盘图标和可用空间信息
- **AND** 顶部不显示 `CleanMac` 文字标识
- **AND** 菜单栏图标、应用名称和主清理操作保持不变

#### Scenario: 复核候选项

- **WHEN** 统一扫描发现需要确认的候选项
- **THEN** 同一主界面按类型分组展示候选项
- **AND** 不自动选中应用残留、项目依赖或大文件扫描候选项

#### Scenario: Provider 空结果状态

- **WHEN** provider 扫描结果为 0 项
- **THEN** provider 状态行使用正常完成图标，不使用感叹号图标
- **AND** provider 的状态行仍保留 0 项文案
- **AND** partial 且存在候选项时继续使用警示图标

#### Scenario: 过滤空清理候选

- **WHEN** 可清理文件或目录的实际大小明确为 0 KB
- **THEN** 应用不将其展示为可清理候选项
- **AND** 大小未知的内容仍可作为候选项展示

#### Scenario: 展示已选与总大小

- **WHEN** 候选列表展示“可清理项目”标题
- **THEN** 标题右侧显示当前已选候选项的大小和全部候选项的已知大小总和
- **AND** 两个大小值使用 `/` 分隔

#### Scenario: 限制可清理项目卡片高度

- **WHEN** 可清理候选项卡片展示
- **THEN** 卡片（包含标题和列表）最大高度为 `640pt`
- **AND** 超出卡片可用高度时只有列表内容在卡片内部滚动，不继续扩大主面板
- **AND** 卡片上方的扫描区域和下方的操作区不受该高度限制
- **AND** 当屏幕可用高度不足时，卡片上限随可用区域降低，主面板不超出屏幕可视区域

#### Scenario: 点击候选项名称选择

- **WHEN** 用户点击可选候选项的名称
- **THEN** 应用切换该候选项的选中状态
- **AND** 点击选择图标与点击名称使用相同的切换逻辑
- **AND** 点击路径、大小或行内空白不触发选择
- **AND** 已完成、受保护或其他不可选候选项不响应选择操作

#### Scenario: 清理执行期间保持操作按钮

- **WHEN** 用户点击“移到废纸篓”并进入清理执行状态
- **THEN** “移到废纸篓”按钮继续显示但处于禁用状态
- **AND** 圆球显示“正在清理”
- **AND** “完成”按钮继续显示但处于禁用状态，不可中断当前流程
- **AND** 操作区从左到右依次排列“移到废纸篓”、重新扫描和完成/取消，重新扫描隐藏时不改变主操作的最左位置
- **WHEN** 清理完成或部分完成
- **THEN** 圆球显示“清理完成”
- **AND** 完成操作恢复可用
- **AND** 候选项目列表继续保留在当前界面，不因状态切换重置
- **AND** 候选项目列表保持清理前的滚动位置

## ADDED Requirements

### Requirement: 主题色与应用图标保持一致

应用 SHALL 以 `#3FA796` 作为唯一主色，以 `#E8D9B5` 作为低频辅助色，并为失败状态提供低饱和暖砖红。面板边框和正文 SHALL 使用系统颜色，面板背景 SHALL 使用透明系统材质，避免多套强调色破坏整体层级，同时保留桌面环境色经过模糊后的自然透出。

#### Scenario: 主操作使用品牌色

- **WHEN** 用户查看主操作、一般强调或扫描中的进度状态
- **THEN** 相关颜色使用 `#3FA796`
- **AND** 主操作前景使用白色，保证小字号文字与品牌色按钮背景形成清晰对比
- **AND** 圆形主操作内部文字使用白色，保证两个主操作的前景色视觉一致

#### Scenario: 主操作按钮保持统一

- **WHEN** 用户查看圆形主操作或“移到废纸篓”按钮
- **THEN** 两者使用同一 `#3FA796` 主操作背景
- **AND** 两者使用同一白色前景
- **AND** 重新扫描、完成和取消按钮继续使用中性次要样式

#### Scenario: 状态颜色保持语义区分

- **WHEN** 界面展示成功、警告或失败状态
- **THEN** 成功、选中和正在扫描使用 `#3FA796`
- **AND** 取消、受保护说明和低风险 partial 使用系统次要文本色
- **AND** 失败使用低饱和暖砖红色

#### Scenario: 菜单栏图标保持系统模板行为

- **WHEN** macOS 在菜单栏显示 CleanMac 图标
- **THEN** 图标继续使用 template rendering 的单色行为
- **AND** 主题色调整不改变菜单栏图标的系统适配方式

#### Scenario: App Icon 使用当前主题色

- **WHEN** 用户查看 CleanMac 的 App Icon
- **THEN** 圆角方形背景使用当前主题色 `#3FA796`
- **AND** 米白色六边形环、内外六边形比例和四角透明区域保持不变
- **AND** `AppIcon.appiconset` 的所有尺寸使用一致的主题色与几何结构
- **AND** 备用 `icon-source.svg` 使用相同的主题色、六边形结构和透明圆角
- **AND** 菜单栏图标继续保持黑色 template 资源，不因 App Icon 配色同步而改变

#### Scenario: 清理成功结果保持简洁

- **WHEN** 候选项清理成功并进入 `movedToTrash` 或 `removed` 状态
- **THEN** 候选行保留成功图标
- **AND** 不在路径下方重复显示“已移到废纸篓”或“已清理”等成功结果文案
- **WHEN** 候选项失败、跳过或取消
- **THEN** 候选行继续显示对应的结果文案，失败时优先显示具体失败消息

#### Scenario: 主题色与毛玻璃层次保持协调

- **WHEN** 用户查看主操作、成功、警告或失败状态
- **THEN** 主操作、品牌强调、成功、选中和正在扫描使用 `#3FA796`
- **AND** 辅助色 `#E8D9B5` 只用于低频背景或细节强调，不用于正文或小字号前景
- **AND** 失败使用低饱和暖砖红色
- **WHEN** 用户查看主弹出层或内容面板
- **THEN** 界面继续使用系统毛玻璃材质
- **AND** 桌面颜色可以经过模糊后自然透出，不固定为浅蓝、浅灰绿或其他品牌底色
- **AND** 不使用不透明纯色背景覆盖主弹出层或内容面板的系统材质
- **AND** 三个内容面板使用透明系统材质和低对比度描边，保留现有内容分组
- **AND** 内容区域不使用 `Color.theme.panel` 作为不透明底层
- **AND** 主界面使用无边框面板和单层系统透明材质，不依赖 `NSPopover` 默认表面
- **AND** 面板、材质视图、HostingView 和内容窗口使用同一个动态系统外观
- **AND** SwiftUI 根内容保持透明，不重复承载 AppKit 材质或自定义不透明根背景
- **AND** 面板内唯一的原生背景视图使用接近输入法菜单的 `.menu` 材质
- **AND** HostingView 和面板内容窗口保持透明，实际模糊由单层 AppKit 材质和 SwiftUI 系统材质提供
- **AND** 面板使用自适应中性系统底色降低桌面环境色影响，不使用固定浅蓝或灰绿色

#### Scenario: 语义状态使用系统色

- **WHEN** 用户查看选中、成功、警告或失败状态
- **THEN** 选中、成功和正在扫描使用 `#3FA796`
- **AND** 取消、受保护说明和低风险 partial 使用系统次要文本色
- **AND** 失败使用低饱和暖砖红
- **AND** 主操作和品牌强调使用 `#3FA796`

#### Scenario: 权限提示使用中性信息层级

- **WHEN** 用户查看完全磁盘访问权限提示
- **THEN** 权限提示使用 `lock.shield` 图标并采用 `#3FA796`
- **AND** “去设置”操作使用 `#3FA796`
- **AND** “去设置”右侧不显示重新检查图标
- **AND** 权限提示整体不使用警告色作为主要前景色
- **AND** 权限提示、扫描进度和可清理项目面板使用同一套透明材质层级
- **AND** 候选 partial、取消和受保护说明使用系统次要文本色

### Requirement: 透明毛玻璃应用背景

应用 SHALL 使用与 macOS 输入法菜单相近的透明毛玻璃背景。背景需要保留桌面环境色的柔和透出和模糊效果，不得通过固定浅蓝色或其他不透明主题色替代系统材质。参考图只约束透明材质的视觉表现，不约束应用内文字、菜单项或布局。

#### Scenario: 桌面背景能够柔和透出

- **WHEN** 用户在白色、蓝色或其他彩色桌面背景上打开主弹出面板
- **THEN** 主弹出面板能够观察到桌面环境色的变化
- **AND** 桌面图案经过毛玻璃模糊，不以清晰细节穿透面板
- **AND** 面板不会固定呈现浅蓝或浅灰绿

#### Scenario: 内容面板保持整体通透

- **WHEN** 用户查看权限提示、扫描进度或可清理项目区域
- **THEN** 内容面板使用透明系统材质或透明根背景
- **AND** 内容区域与面板边缘之间不出现明显的不透明色块断层
- **AND** 面板通过材质强度、圆角和低对比度描边维持内容层级

#### Scenario: 明暗主题同步

- **WHEN** 用户切换浅色、深色或跟随系统主题
- **THEN** 面板、HostingView、内容窗口和 SwiftUI 根视图使用同一个 effective appearance
- **AND** 透明材质自动采用对应主题的亮度与对比度
- **AND** 正文、按钮和候选项在不同桌面背景下保持可读

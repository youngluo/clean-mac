## Why

工作状态下圆形主操作的视觉阴影与状态面板距离偏近，主界面的间距值也分散在多个视图中，后续调整容易产生局部不一致。与此同时，`CompletedView` 已不再参与统一清理流程，保留它会让维护者误以为存在第二套完成态布局。最新参考图进一步确认，主界面应使用 macOS 菜单相近的透明毛玻璃，而不是固定浅蓝或浅灰绿背景。

## What Changes

- 增加工作状态圆形主操作与 provider 状态面板之间的视觉缓冲，同时保持圆球顶部定位和其他状态布局不变。
- 在当前生效的 SwiftUI 视图中集中管理语义化间距值，保持现有信息层级和紧凑度，减少散落的数字常量。
- 调整 provider 状态图标，0 项时显示正常完成图标；仍有候选项的 partial 状态继续显示警示图标。
- 将圆球的呼吸效果限定在正在扫描状态，清理执行、完成和其他状态保持静态。
- 过滤实际测得为 0 KB 的可清理候选项，保留大小未知的候选项。
- 在“可清理项目”标题右侧同时显示已选大小和全部候选项总大小，并用 `/` 分隔。
- 将“可清理项目”卡片最大高度调整为 `640pt`，只让超出的列表内容在卡片内部滚动；小屏幕上按可视区域进一步降低该上限，上方扫描区和底部操作区保持原有布局。
- 允许直接点击候选项名称切换选中状态，路径、大小和行内空白保持原有行为。
- 点击“移到废纸篓”后保留该按钮但禁用，防止重复触发；清理执行期间同时保留并禁用“完成”按钮，圆球显示“正在清理”，结束后显示“清理完成”。
- 删除未被主界面挂载的 `CompletedView` 及其旧完成态布局。
- 将主色、辅助色和失败色收敛为 `#3FA796`、`#E8D9B5` 和低饱和暖砖红，取消独立警告色，减少视觉噪声。
- 清理成功的候选项仅保留成功图标，不再重复显示“已移到废纸篓”等成功结果文案。
- 将“移到废纸篓”作为操作区最左侧的主操作，重新扫描和完成操作依次排列在其右侧。
- 将主色、辅助色和失败色收敛为单一配色体系，减少状态色数量，并保持主弹出层与内部面板的视觉层级。
- 按参考图使用 macOS 原生透明毛玻璃作为整体背景，让桌面颜色经过模糊后自然透出，不使用固定浅蓝、浅灰绿或品牌色作为大面积底色。
- 将主界面背景从 `NSPopover` 迁移到单层无边框 `NSPanel`，由 AppKit `.menu` 材质承接背景，避免 Popover 默认表面过灰过厚。
- 将选中、成功和正在扫描状态统一为品牌青绿色，将取消、受保护说明和低风险 partial 状态降级为系统次要文本色，失败状态使用低饱和暖砖红。
- 清理完成后保留候选项目列表及其当前滚动位置，不因状态切换重新挂载清理视图。
- 将主操作按钮与圆形主操作统一为 `#3FA796`，使用深青黑前景增强文字对比度。
- 同步面板、材质视图、HostingView 与 SwiftUI 根背景的动态外观，保持浅色、深色和跟随系统主题下的表面一致。
- 将三个内容面板改为透明系统材质和低对比度描边，保留现有信息分组与圆角，但不再用不透明主题表面覆盖桌面背景。
- 将完全磁盘访问提示改为主色图标与操作链接，避免引入额外的系统蓝。
- 移除主界面顶部的 `CleanMac` 文字标识，保留启动磁盘信息和功能内容，减少重复品牌信息。
- 将圆形主操作内的文字固定为白色，并让主操作按钮沿用相同前景，保持品牌色背景上的识别度。
- 让浅色、深色和跟随系统主题都使用对应的系统材质，透明度、模糊和桌面背景随 macOS 外观变化，不单独维护浅蓝色背景。
- 将“移到废纸篓”按钮文字改为与圆球相同的白色，统一两个主操作的前景表现。
- 使用单层无边框 `NSPanel` 承载主界面，内容窗口和 HostingView 保持透明，面板内只放置一个 `.menu` `NSVisualEffectView`，并叠加自适应中性系统底色以降低环境色影响；内部面板只叠加系统毛玻璃和细描边，使整体接近参考图的统一透明面板。
- 将 App Icon 的背景色同步为当前主题色 `#3FA796`，保留米白六边形、圆角透明裁切和现有资源尺寸映射；菜单栏图标继续保持黑色 template 资源。
- 增加与当前 App Icon 几何和配色一致的 `icon-source.svg` 备用源文件，不改变 asset catalog 的 PNG 映射。

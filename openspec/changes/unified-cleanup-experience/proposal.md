## Why

CleanMac 当前把一键清理、大文件扫描和开发清理拆成多个入口，用户需要判断进入哪个流程，且一键清理不会统一检查启动磁盘、应用残留、安装包和项目依赖。现在需要将所有检查收敛到一个主界面，在保持安全边界的同时让用户通过一次点击获得完整进度和结果。

## What Changes

- **BREAKING** 将多个清理入口合并为单一主界面和唯一的“一键清理”入口。
- 在同一界面内展示统一扫描、待确认项目、确认操作和最终结果，不再单独进入大文件扫描页面。
- 检查完成后继续留在主界面，圆形主操作显示“检查完成”并停止呼吸动效，provider 日志下方直接展示候选结果和确认操作。
- 统一检查深度清理、已卸载应用残留、缓存与服务、项目构建产物，以及合并后的大文件扫描（安装包、启动磁盘文件和目录、Time Machine）。
- 扫描阶段只读取和计算，不执行任何删除；所有可删除项目都必须经过用户最终确认。
- 安全项目可以默认勾选，应用、残留、大文件扫描候选和项目依赖默认不勾选。
- 最终确认后，所有文件和目录统一进入 macOS 废纸篓，并展示逐项结果。
- 候选项将完整路径置于信息顶部，支持中间省略、悬停查看完整路径和点击打开；确认移除与取消操作在底部并列展示。
- 为 `node_modules` 增加项目归属、lock 文件、使用中和符号链接保护；允许计算整体体积，但不展示内部文件，不设置大小阈值。
- 优化全盘遍历的元数据读取和取消检查，减少重复属性访问，但不缩小启动磁盘扫描范围或改变隐私排除边界。
- 将磁盘访问提示改为简短、柔和且单行可读的授权文案。
- 将权限提示右侧操作整理为统一高度、紧凑间距的操作组，避免按钮与说明文字互相挤压。
- “去设置”操作仅保留文字，避免图标造成视觉噪音。
- 统一所有可用的界面操作使用手形指针，禁用操作保持默认指针。
- 为圆形“一键清理”使用 macOS 系统蓝，并保留克制的白色悬停边缘和按下回弹。
- 将主按钮图标改为白色单色橡皮擦，扫描状态通过整个圆形按钮的轻微运动表达工作状态。
- 检查和清理进行中不显示额外 loading，改为让整个圆形主按钮做轻微呼吸、抬升和倾斜运动。
- 将主操作设计为圆形“一键清理”按钮，并为扫描进度、清理进度和完成结果提供克制的状态动画。
- 统一权限、部分扫描、失败、跳过、确认取消和待确认项目的结果展示。

## Impact

- 修改 `CleanerViewModel`、清理模型、扫描/执行服务和 SwiftUI 主界面状态流。
- 增加应用本体及残留、安装包、缓存服务和项目依赖候选的扫描与安全策略。
- 保留现有废纸篓路由、权限限制、照片图库排除、启动磁盘边界和 Time Machine 安全确认。
- 扩展服务、视图模型和 UI 测试，并执行 Debug 构建和运行验证。
